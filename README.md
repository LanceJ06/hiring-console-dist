# Hiring Console - download host

This repository exists only to host an installable build of an internal
recruiting console so staff can put it on their phones.

There is no source code here. The application source is in a separate private
repository.

The build under Releases is a **debug** build of a thin native wrapper around a
private, sign-in-only web console. It is not a general-purpose app and is not
supported for any other use. It requests only internet access.
